Campi Obbligatori File CSV:
  • tipo_intervento: Tipo servizio (es. Tagliando, Revisione, Freni)
  • targa: Targa autoveicolo (es. AA123BB)
  • data: Data intervento (es. 2026-05-15 o 15/05/2026)
  • km: Chilometraggio (es. 45000)
  • descrizione: Note o dettagli lavoro eseguito
  • officina: Nome officina / luogo esecuzione
  • importo: Costo in Euro (es. 250.00)
Controlli Automatici: Il sistema evidenzierà i record senza autoveicolo in anagrafica ed escluderà le righe duplicate (stessa targa, data ed importo).
