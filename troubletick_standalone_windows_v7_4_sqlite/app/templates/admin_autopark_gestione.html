Importazione Dati (CSV)

Carica un file CSV per inserire o aggiornare gli automezzi. I record esistenti con la stessa targa saranno sovrascritti.

Il file deve contenere l'intestazione con questi campi:
targa, marca, modello, tipo, colore, alimentazione, data_immatricolazione, proprieta, canone_noleggio, km_attuali, stato, sede_assegnata_id, sede_attuale_id, reparto_assegnato_id.
Area Pericolosa

Questa operazione elimina in modo definitivo tutti gli automezzi presenti nella flotta aziendale.
